# Dress 3 — v1.0.0

Première distribution **Windows x64 portable** de Dress 3, par Bilal Boudjemline — Threadlock Systems.

## Inclus
- Dressing local avec catégories, filtres, import et fiches des vêtements.
- Analyse locale des couleurs et détourage manuel ou automatique, modèles embarqués.
- Création de tenues aléatoires ou sur mesure et sauvegarde des compositions.
- Fit Memory : carnet de profils de tailles et mensurations.
- Apparence personnalisable et météo Open-Meteo pour Cambrai, Proville et Créteil.

## Installation
Télécharger `Dress3-1.0.0-windows.zip`, extraire **tout** le contenu et lancer `Dress3.exe`. Garder `resources.neu` à côté de l'exécutable. Microsoft Edge WebView2 Runtime est requis.

Le programme n'est pas signé : Windows peut afficher un avertissement de réputation. Ne télécharger que depuis ce dépôt officiel et vérifier l'empreinte SHA-256 du ZIP dans `update.json`.

## Données et mises à jour
Au premier lancement, Dress 3 prépare `Documents/dress3_data` et mémorise son emplacement. Si ce dossier n'est pas accessible, ouvrir Paramètres pour choisir un emplacement.

Pour les prochaines versions : fermer l'application, extraire le nouveau ZIP dans un nouveau dossier puis lancer le nouvel exécutable. **Ne pas remplacer ni supprimer `dress3_data`.** Sauvegarder ses données avant toute mise à jour.

`update.json` contient la version, l'URL du ZIP, sa taille et son SHA-256. Les mises à jour sont **manuelles** : aucune installation ni recherche automatique n'est intégrée à cette version.

Le ZIP contient les modèles ONNX pour le fonctionnement local, ce qui explique son volume. Aucun vêtement ni donnée personnelle n'est inclus. Les licences et crédits sont fournis dans l'archive.
