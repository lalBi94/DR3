# Dress 3 — v1.0.1

Correctif d'interface : le nom **Dress 3** est désormais intégré à la barre de navigation. Le grand titre séparé au-dessus a été retiré pour rendre l'en-tête plus compact.

Aucun changement du format des données ni migration nécessaire.

## Installer le correctif
1. Télécharger `Dress3-1.0.1-windows.zip` et fermer Dress 3.
2. Extraire tout le ZIP dans un nouveau dossier et lancer `Dress3.exe`.
3. Conserver `resources.neu` à côté de l'exécutable et actualiser son raccourci si nécessaire.

**Ne pas effacer ni remplacer `dress3_data`.** Le chemin mémorisé et les données existantes sont conservés. Une sauvegarde des données reste recommandée.

Le manifeste `update.json` fournit la version, l'URL du ZIP, sa taille et son SHA-256. Les mises à jour restent manuelles, sans bouton intégré. Windows x64 avec Microsoft Edge WebView2 Runtime requis ; exécutable non signé.

Les modèles locaux, licences et crédits restent inclus. Aucun code source du projet ni donnée utilisateur n'est publié.
