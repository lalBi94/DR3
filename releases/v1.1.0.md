# Dress 3 — v1.1.0

## Nouveau : installation des mises à jour depuis Paramètres

Dans **Paramètres → Mises à jour de Dress 3** :
1. Dress 3 recherche la dernière version stable sur ce dépôt GitHub. Le bouton permet de relancer la recherche.
2. Si une nouvelle version existe, sa version et la taille du téléchargement sont affichées.
3. Enregistrer ses travaux, cocher la confirmation puis cliquer sur **Mettre à jour et redémarrer**.
4. L'archive est téléchargée et vérifiée (taille et SHA-256), puis Dress 3 se ferme, remplace ses fichiers et redémarre automatiquement.

Aucune installation silencieuse n'est déclenchée au démarrage. Une erreur réseau laisse le dressing utilisable hors ligne. Le dossier de l'application doit être accessible en écriture ; l'outil ne demande pas de droits administrateur.

## Passer depuis v1.0.0 ou v1.0.1

Ces versions ne possèdent pas le mécanisme intégré : **installer cette v1.1.0 manuellement une dernière fois**. Fermer Dress 3, extraire tout le ZIP dans un nouveau dossier et lancer `Dress3.exe`. Garder `resources.neu` à côté de l'exécutable.

Ne pas supprimer ni remplacer `dress3_data`. Le chemin mémorisé, vêtements, tenues, profils de tailles et préférences sont conservés. Une sauvegarde avant mise à jour reste recommandée.

Les versions suivantes pourront être installées depuis Paramètres, sans télécharger et extraire le ZIP manuellement.

## Sécurité et limites
- Windows x64, Microsoft Edge WebView2 Runtime et Windows PowerShell requis.
- Téléchargements uniquement depuis les releases officielles ; refus des archives inattendues ou corrompues.
- Sauvegarde des fichiers de l'application avant remplacement et restauration en cas d'échec détecté. Les données utilisateur ne sont pas remplacées.
- En cas d'arrêt brutal de Windows pendant le remplacement, une restauration manuelle peut être nécessaire. Les sauvegardes et diagnostics sont alors dans le temporaire `dress3-update-<identifiant>` indiqué dans l'erreur.
- Exécutable non signé : avertissement Windows possible. SHA-256 vérifie l'intégrité, mais ne remplace pas une signature d'éditeur indépendante.
- Les modèles locaux restent embarqués : le téléchargement comprend l'application complète.

Les sources de développement et les données personnelles ne sont pas publiées. Licences et crédits inclus dans le ZIP.
